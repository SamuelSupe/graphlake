# 48ec1bc 性能与稳定性审查处理记录

修复以审查点名的提交为基线。下面覆盖附件可见的 19 条编号问题和 5 条低优先级观察。

| 项目 | 处理 |
| --- | --- |
| 1. 驱动反复确认主权 | Bolt 建连、登录与消息、Gremlin 会话使用本地主权窗口。心跳继续维护窗口并取消已失效的在途查询；不可逆删除和写入继续确认主权或使用 etcd 事务围栏。 |
| 2. 托管本地表 GC 饥饿 | 同一轮回收此前已标记且宽限期已过的代次、标记新到期代次，并用同一次 CAS 保存；单表错误不阻断其余表。 |
| 3. 集群 CSR 变长路径 | 深度优先扩展在查询 Worker 扫描分区块，复用块缓存，免除逐顶点远程派发。最短路径的层级调度保留。 |
| 4. 相关 CALL 变长路径 | 批处理首个 MATCH 从导入实体获取起点，复用查询内拓扑。复杂分支或无法证明起点约束时使用通用遍历；无分页和排序的关系计划原本只扫描一次。 |
| 5. 单机 CSR 缓存 | 近期拓扑缓存提高到 512 MiB，保持查询内预算和文件变更检查；同一缓存串行解码未命中的拓扑。超过缓存上限的拓扑仍按需加载。 |
| 6. 大于 1024 行的增量 | 索引增量以已有的字节上限、内存及快照边界来准入，与 Arrow 批大小解耦。超过增量边界的任务仍可回退到重写。 |
| 7. MCP schema 争用 | 默认只读发布结构；显式指定 `include_types: true` 才访问来源，使用独立名额。 |
| 8. 驱动路径回查 | Bolt 和 Gremlin 对有多个结果的直接路径列分批去重回查；保留逐行输出预算，超大批回退到原路径。 |
| 9. 未认证占用会话 | Bolt 和 Gremlin 均使用独立的已认证和认证中名额。认证中名额满时仍可能拒绝新握手，不会挤掉现有认证会话。 |
| 10. 慢下载占槽 | 60 秒无进度或 15 分钟总时长触发释放。 |
| 11. 主权窗口锁内写盘 | 先发布围栏和取消信号，再释放窗口锁，将选举指标持久化交给阻塞线程。 |
| 12. CSR manifest 重读 | 按不可变代次复用最近两个 manifest，合并同一代次的并发加载，并将 JSON 解码移出异步工作线程。 |
| 13. CSR 自动刷新重试 | 同一模型 revision 连续失败按 30 秒到 16 分钟退避，成功或 revision 变更后从初始间隔开始。 |
| 14. CSR 块写入 | 并行上传有上限，manifest 保持分片和块顺序；边身份块从 32 KiB 合并到 256 KiB。 |
| 15. MySQL 兼容来源取消 | 物化扫描持有可取消连接，失败或取消复用原有 KILL 路径。完成后把连接交还读快照。 |
| 16. 连接重复构建 | 对象存储、MongoDB 和数仓 HTTP 复用有上限的客户端缓存。缓存键区分连接设置和凭证；MongoDB 还区分运行时。 |
| 17. 托管同步失败重下载 | 已提交代次和本地文件版本均匹配时复用工作区；工作区已改变则从已提交快照恢复。连续失败退避，手动同步可立即发起。 |
| 18. 分组 collect 溢写 | 溢写 run 记录共享文件中的字节区间，避免每组常驻打开文件；合并复用专用运行时。 |
| 19. Node2Vec | 训练移到阻塞线程，循环检查取消和截止时间，维度上限 1024。 |
| 审计日志 | 写入和轮转保留串行顺序，阻塞写盘让出多线程 Tokio 的调度能力。 |
| SQLite 内存计费 | 每行预留一次；在复制字段之前计费。 |
| 快照溢写 | 同步 IPC 读写在阻塞区执行，释放多线程 Tokio 的调度能力。 |
| 托管工作区位置 | 工作区和键索引使用数据目录所在的文件系统。 |
| 预览临时文件和定时器 | 预览和下载凭证由一个回收任务处理；仍为支持 Arrow 下载的结果生成临时文件。 |

额外修复了测试中发现的并发会话问题：检查和更新使用加锁后的时间，避免较早取样的并发请求误删刚续期的会话。

验证覆盖了多批 CALL 的 33 个导入起点、超过 1024 行的增量复用基线、持续有进度的下载到期释放、真实 etcd/S3 上的 GC 标记与删除、MySQL 协议物化读取消、集群重启和 Worker 下线、托管快照固定与备份恢复，以及 Neo4j 和 Gremlin 客户端的原生路径和分批传输。测试结果不能用于推断生产吞吐或 P99，也没有用真实 MongoDB 实例测量连接缓存收益。

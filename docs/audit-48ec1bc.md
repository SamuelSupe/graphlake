# 48ec1bc 性能与稳定性审查处理记录

修复以审查点名的提交为基线。下面覆盖附件可见的 19 条编号问题和 5 条低优先级观察。

| 项目 | 处理 |
| --- | --- |
| 1. 驱动反复确认主权 | Bolt 建连、登录与消息、Gremlin 会话使用本地主权窗口。心跳继续维护窗口并取消已失效的在途查询；不可逆删除和写入继续确认主权或使用 etcd 事务围栏。 |
| 2. 托管本地表 GC 饥饿 | 同一轮回收已过宽限期的代次并标记新到期代次。同步前进导致 CAS 冲突时仅合并对原退役代次的决定。固定当前快照只写租约记录，避免查询争用表状态。单表错误不阻断其余表。 |
| 3. 集群 CSR 变长路径 | 深度优先扩展在查询 Worker 扫描分区块，复用块缓存，免除逐顶点远程派发。最短路径的层级调度保留。 |
| 4. 相关 CALL 变长路径 | 批处理首个 MATCH 从静态类型的导入实体获取起点，覆盖同类型和不同类型的节点键、多关系类型和通配关系。单机在各批之间复用查询内拓扑，集群 CSR 直接从导入键开始。无法证明起点约束的分支继续使用通用起点筛选。 |
| 5. 单机 CSR 缓存 | 近期拓扑缓存保留 512 MiB 上限。仅同一文件版本和方向的解码互相等待，超过保留上限的拓扑也在活跃查询间共享。保留查询内预算和文件变更检查。 |
| 6. 大于 1024 行的增量 | 索引增量以已有的字节上限、内存及快照边界来准入，与 Arrow 批大小解耦。超出增量边界后，整数、字符串和二进制主键使用磁盘键索引分批重写，其他主键使用可溢写的归并反连接。提交继续遵守删除标记和原子水位更新语义。 |
| 7. MCP schema 争用 | 默认只读发布结构；显式指定 `include_types: true` 才访问来源，使用独立名额。 |
| 8. 驱动路径回查 | Bolt 和 Gremlin 对有多个结果的直接路径列分批去重回查；保留逐行输出预算，Gremlin 回退到单条路径时仍对其实体分组回查。 |
| 9. 未认证占用会话 | Bolt 和 Gremlin 各有独立的已认证和认证中名额。Bolt 每个 TCP 对端 IP 最多占用 8 个认证中名额，超额的连接在有拒绝响应名额时于 `HELLO` 后收到可重试的 `FAILURE`。Gremlin 保留一个 500 毫秒的额外名额，全部占用时返回 HTTP 429。 |
| 10. 慢下载占槽 | 两个并发下载名额，每个身份最多占用一个。每次传输数据续期 60 秒，停滞时释放名额。S3 的 Arrow 下载也采用进度超时。 |
| 11. 主权窗口锁内写盘 | 先发布围栏和取消信号，再释放窗口锁，将选举指标持久化交给阻塞线程。 |
| 12. CSR manifest 重读 | 每模型保留最近使用的两个代次，进程内最多缓存 256 条且按 JSON 大小合计最多 128 MiB。加载中的条目独立于淘汰，合并同代次的并发加载，JSON 解码在阻塞线程执行。 |
| 13. CSR 自动刷新重试 | 同一模型 revision 连续失败按 30 秒到 16 分钟退避，成功或 revision 变更后从初始间隔开始。 |
| 14. CSR 块写入 | 顶点、边和属性块上传采用有界并发，manifest 保持分片和块顺序。边身份块从 32 KiB 合并到 256 KiB。 |
| 15. MySQL 兼容来源取消 | 物化扫描持有可取消连接，失败或取消复用原有 KILL 路径。完成后把连接交还读快照。 |
| 16. 连接重复构建 | 对象存储、MongoDB 和数仓 HTTP 复用有上限的客户端缓存。缓存键区分连接设置和凭证，GCS 凭证文件在原路径轮换时也会重新建连。MongoDB 还区分运行时。 |
| 17. 托管同步失败重下载 | 本地改写和上传期间保留已提交分片。重试以 etcd 中的已提交代次为基准，校验后复用本地文件，只从 S3 获取缺失或校验失败的分片。连续失败退避，手动同步可立即发起。 |
| 18. 分组 collect 溢写 | 溢写 run 记录共享文件中的字节区间，避免每组常驻打开文件。DISTINCT 合并复用专用运行时。普通及 DISTINCT 两条路径的同步读写均在阻塞区执行。 |
| 19. Node2Vec | 训练移到阻塞线程，循环检查取消和截止时间，维度上限 1024。 |
| 审计日志 | 独立写入线程经有界队列接收事件并负责文件轮转。调用方仍在写入完成后返回，磁盘 IO 不持有请求侧全局锁。 |
| SQLite 内存计费 | 每行预留一次；在复制字段之前计费。 |
| 快照溢写 | 同步 IPC 读写在阻塞区执行，释放多线程 Tokio 的调度能力。 |
| 托管工作区位置 | 工作区和 SQLite 键索引位于 Coordinator 本机临时盘，可用 `TMPDIR` 选择本地磁盘。 |
| 预览临时文件和定时器 | 预览和下载凭证由一个回收任务处理。1 MiB 以内的 Arrow 预览留在内存，较大的合规预览再创建临时文件。 |

额外修复了测试中发现的并发会话问题：检查和更新使用加锁后的时间，避免较早取样的并发请求误删刚续期的会话。

验证覆盖了多批 CALL 的 33 个导入起点、集群异构节点的关联 CALL、超过 1024 行的增量复用基线、24 MiB 内存预算下含删除标记的大增量重写、Arrow 预览与导出、持续传输与停滞下载、真实 etcd/S3 上的快照固定和回收、MySQL 物化读取消，以及协调器重启、Worker 下线和备份恢复。Neo4j 和 Gremlin 客户端回归覆盖原生路径、分批传输和握手限额。性能验证以回归场景为限，生产吞吐、P99 和真实 MongoDB 连接复用收益尚未测量。

本次复查扩展了关联 CALL 回归，核对多类型和通配关系的输出及实际展开数。S3 故障注入先拒绝写入，再拒绝读取原代次的分片。上一版在重试时失败，修复后完成重试并维持已提交代次与行数。GCS 凭证轮换检查覆盖了同一文件路径、同一长度但内容变化的缓存失效。
